DS Simulator - Windows x64 prototype

실행 방법
1. DS-Simulator.exe 파일 하나를 다운로드합니다.
2. DS-Simulator.exe를 더블클릭합니다.
Python, VS Code, CMD 파일, 압축 해제, 추가 라이브러리 폴더가 필요하지 않습니다.
필요한 런타임은 EXE에 포함되어 있으며 실행 시 임시 폴더에서 로드합니다.

첫 사용
- 엑셀 가져오기: .xlsx/.xlsm 파일 → (데이터) 시트 하나 선택 → 확인.
- A opcode / B 연동자료명으로 메시지를 구분합니다. C~K는 읽기 전용 고정 정의이며 M열만 줄바꿈 구분 항목을 선택합니다.
- 표의 순번·데이터 요소와 M 설정값은 가로 스크롤 중에도 보입니다. M이 비면 입력 불가입니다. 원본 파일은 수정하거나 업로드하지 않습니다.
- 시나리오에서는 데이터 요소 표에서 편집을 눌러 같은 표를 넓게 엽니다. 이전 E열 저장본은 새 규칙을 적용하려면 Excel을 다시 가져오세요.
- 수식 셀은 Excel이 저장한 계산 결과를 읽습니다. 결과가 없으면 Excel에서 Ctrl+Alt+F9로 재계산 후 저장하고 다시 가져오세요.
- 기본 모드는 실제 통신 LIVE이며 모든 소켓은 미연결입니다. 선택한 연결 설정 편집에서 Local/Remote IP·Port를 입력한 뒤 연결하세요.
- TCP 서버는 실제 접속한 클라이언트가 트리에 자동 표시됩니다. 대상 클라이언트를 한 개 선택하세요.
- HEX 직접 송신(AA BB 00 01) 또는 UTF-8 직접 송신으로 실제 데이터를 보냅니다. 받은 원문은 LIVE RX 로그에 자동 기록됩니다.
- ICD 바이너리 규격은 아직 미정이라 실제 ICD 자동 인코딩은 하지 않습니다. 임의 헤더/길이/체크섬을 추가하지 않습니다.
- 기존 ICD 필드 편집·예시 수신은 상단에서 모의 통신 MOCK을 선택하세요. 모드를 바꾸면 모든 연결을 해제합니다.
- 스펙트럼 메뉴는 별도 창을 엽니다. 메인 화면을 계속 사용할 수 있습니다.
- 하단 통신 모니터는 연결별 TX/RX 타임라인과 초당 건수를 표시합니다.
- 모니터의 화면 일시정지는 수집을 중지하지 않습니다.
- 왼쪽 송수신 로그 메뉴에서 검색·상세·내보내기를 사용합니다.
- 시나리오: 실제 통신은 직접 송신 블록(HEX/UTF-8)을 대기·반복과 함께 사용합니다. 기존 ICD 송신 블록은 모의 모드에서만 실행합니다.
- 기본 예제는 주파수 설정 → 500ms 대기 → 상태 조회를 10회 반복합니다.
- 기본 예제는 프로그램에 내장되어 있습니다. 예제 JSON은 소스 저장소의 prototype/examples에도 있습니다.
- 저장 파일은 사용자가 파일 대화상자에서 선택한 위치에 저장됩니다.

이 버전은 실제 IPv4 TCP/UDP 원문 통신과 별도 모의 모드를 제공합니다.
TX의 QUEUED/OS_ACCEPTED는 송신 버퍼/운영체제 접수이며 상대 수신이나 시험 합격을 의미하지 않습니다.
TCP 로그 한 건은 바이트 스트림의 조각이며 ICD 한 메시지라고 볼 수 없습니다.
계측기 제어, ICD 자동 인코딩/디코딩, FFT, 10G 성능 검증은 구현하지 않았습니다.
Excel 가져오기는 A~K·M열, 2행부터, 선택한 (데이터) 시트 한 개를 지원합니다. L과 N 이후는 사용하지 않습니다.
스펙트럼은 정적 예시이며 실제 장비 측정 결과가 아닙니다.

검증 정보
빌드 커밋과 EXE 단독 실행 검사 결과는 GitHub Actions의 validation/build-info.json에서 확인할 수 있습니다.
검사는 GUI를 화면 밖에서 렌더링하는 방식이며 실제 장비 시험을 의미하지 않습니다.
